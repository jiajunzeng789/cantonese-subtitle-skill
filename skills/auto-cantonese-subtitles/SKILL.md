# 汽车粤语书面语单行字幕

## 执行边界

- 语音识别与媒体处理在本地完成，不上传音视频到识别 API。准备时可下载公开模型和依赖；离线处理时不自动下载或改用云端。
- 由当前助手进行文字校准。助手使用在线模型时，转写文本会交给在线模型，不得描述为全链路离线。若用户要求文字也离线，则使用本地文本模型，缺少时说明实际限制。
- 最终交付 UTF-8 `.srt`，每条恰好一行文字，带对应原媒体的时间轴，不以纯文本稿代替。
- **默认只制作并交付SRT。** 不烧录字幕、不生成横竖屏预览/试听视频、不为验收抽帧，也不为此安装或更换字幕滤镜。只有用户明确要求预览视频、字幕烧录或画面核对时，才执行这些额外工作。中间识别JSON和校准记录可内部保存；有未决疑点时在回复中简要列出，不自动增加其他交付文件。
- 默认无句读标点，保留数值、单位及正式名称必需符号，例如 `1.8米`、`30%`、`-5℃`、`0—100km/h`、`CX-5`。不能把“无标点”理解为删除所有非汉字字符。
- 输入、原始识别结果、校准记录和最终字幕分别保存，不覆盖原文件。

## 环境与任务反馈

- **macOS离线安装包。** 若已通过一键安装，读取个人环境记录中的 `python_executable`、`tools_bin`、`models_manifest`，复用已装的工具与模型；不要因Hugging Face缓存为空就重下模型。脚本会在本次进程中启用记录的FFmpeg路径，不需修改系统PATH。安装包入口见仓库的 `macos/`，使用说明见[统一安装与自检](references/runtime-setup.md)。
- **先展示清单，再执行。** 使用 [references/task-progress.md](references/task-progress.md) 的状态约定，每步验证通过后打勾；进入步骤、完成、失败或等待用户时立即更新。长任务在有执行机会时约每60秒报告当前步骤、耗时和最近进展，不编造百分比，不承诺软件不支持的后台推送。
- **统一脚本准备与自检。** 首次准备或环境故障先按 [references/runtime-setup.md](references/runtime-setup.md) 执行 `scripts/setup_runtime.py`，不要临场拼装安装命令或随意改依赖版本。脚本先只读检查本机记录、已知环境和用户指定解释器，通过则复用，否则分步创建专用环境；安装日志和进度落盘。音频解码、模型加载、短样本推理分别验证。依赖故障的进一步处理见 [references/environment-recovery.md](references/environment-recovery.md)。不修改系统Python，不硬编码开发者电脑路径。
- **国内网络先检查下载源。** 确需安装依赖时，优先检查国内可信HTTPS镜像的可达性及所需版本，再为本次命令临时指定；不修改全局pip设置。提醒应显示实际包名、来源及可获得的下载进度，不能只说“PyTorch较大，请等待”，也不能把全部依赖的体积算成PyTorch大小。详见环境恢复说明。
- **先有证据，再修故障。** 保留完整错误和退出码，区分网络、构建/版本、权限及已证实的安全拦截。仅凭pip失败、临时目录或删除文件字样不能判定安全拦截；不默认要求关闭防护、放行未知文件或重启。需用户操作时说明具体依据、目标操作、影响及恢复方式。
- **失败可续接。** 基础工具、Whisper、Qwen分步准备并保存日志。针对同一错误，有依据修复后最多自动重试一次；仍失败则停止该步骤，报告中断点，继续不依赖它的工作。用户说“继续”时先核对记录及运行中任务，从仍有效的中断点恢复，不重复启动安装或下载。

## 工作流程

1. **确定成片画幅。** 视频用 `scripts/subtitle_profile.py` 探测显示尺寸，考虑旋转和像素宽高比，忽略MP3封面等附图。最终剪辑尺寸优先于源视频，用户指定竖屏时不能按横屏源文件套横屏预设。音频没有画幅：使用用户已给的成片设置；未知时询问横屏或竖屏，也可在用户需要时各出一套，不把猜测称为自动识别。详见 [references/subtitle-layout.md](references/subtitle-layout.md)。
2. **本地识别与交叉检查。** 检查模型完整性，使用 Whisper large-v3 与 Qwen3-ASR-1.7B，保留原文和时间数据。Qwen默认输出文字用于交叉校准，时间定位参考Whisper及原音频；只有需要额外对齐且验证通过时才加载可选ForcedAligner，不把对齐模型作为基础运行的必需下载。相同素材、相同背景词做比较。短样本依次运行；超过180秒使用`scripts/transcribe_long.py`管理重叠窗口、唯一文件名、时间偏移和已完成结果复用，不临时写shell循环。脚本只保守去除时间和文本均匹配的重复片段，其余接缝进入待审；须结合双模型和原音频完成语义去重，不直接拼接窗口正文当成终稿。运行说明见 [references/local-testing.md](references/local-testing.md)。首次对比以无提示词结果为基线。漏段、重复、可疑额外内容须用原音频短片段复测，不能只凭一个模型认定正确。
3. **先校准、后断句。** 当前助手对照两模型原文、相邻语境和本地术语资料，依据 [references/editorial-rules.md](references/editorial-rules.md) 修正专名及同音候选，并生成保留标点的简体书面语工作稿。保留条件、否定、数字、推测和立场。语言推断只生成候选，不等于听音或外部核验。
4. **按画幅拆成单行语义单元。** 不再要求一整句独占一条字幕。允许将长句改写为连续、自然的语义短句，每条能表达一个清楚的小意思。不能按固定字数硬切，不能拆开品牌车型、姓名、固定术语、数字与单位，不能产生孤立连接词或半截主谓/动宾结构。尽量落入画幅建议长度，短回答不为凑字补内容。不要为了缩短而丢条件、数字或改观点。超过长度上限时重新改写或分句，不折行、不截断。
5. **多人发言分别处理。** 不将不同人的问答拼成一句或同一行，不再用两行对话同屏规避短字幕。切入对应本条实际发言；连续发言时上一条显示到下一条切入，再直接切换，不重叠。无说话人分离时不凭文本编造人物身份，轮次不清或重叠人声进入待审，不保证已经解决串人。
6. **逐语义单元匹配时间。** 使用对应原始词/片段的起止点，保留来源映射及媒体偏移。拆出新的短句必须重新定位声音，不把旧长句的时间按字数均分。需要重新定位时使用 `scripts/realign_subtitles.py`，每条提供 `original` 原始粤语及对应书面语 `text`，复用本地Whisper权重；调用见[本地测试说明](references/local-testing.md)。不能用改写后的普通话文本对齐粤语发音。对齐失败则复核或保留明确标识的旧候选，不能伪造精确时间。已有用户确认的切入、只要求调整显示结束时，不重新对齐切入。
7. **连续显示并导出。** 先核准语音切入与原始声音边界，再由 `scripts/export_srt.py` 默认将显示结束衔接下一条切入；长停顿、过长显示、明确转场及最后一条保留原结束时间。显示延长不代表声音也持续到该时刻，不得覆盖来源时间或用延长掩盖零时长对齐。脚本清理句读、转换简体、保护必要符号，并检查单行、宽度、速度、重叠和越界；换行、超宽或明显粤语残留须修正后重试。JSON包含 `media_duration`、`subtitle_profile`、`cues`；连续显示预设、例外和schema见[画幅与导出说明](references/subtitle-layout.md)。同名 `.display.json` 仅作内部显示时间记录，不触发预览制作。
8. **检查SRT并交付。** 检查单行文本、宽度、阅读速度、重叠和原音轨范围；给定字体、字号及安全区时可用Pillow测量文字宽度，不需要渲染视频或抽帧。SRT不可靠携带样式，说明剪辑软件的自动换行取决于最终字幕设置即可，不把视频预览当成交付SRT的前置条件。有实际回听才报告已验证音频同步，结构检查不能视为语义或声学验收。用户另行要求预览时才使用 `.display.json` 制作对应画面。

## 交付

- `<素材名>_横屏.srt` / `<素材名>_竖屏.srt`；未决专名、内容、轮次或时间疑点则用 `.review.srt` 标识待审稿。
- 疑点内部记录时间位置、原识别、候选、依据和未决原因；交付回复简要提示未决项，不把说明塞进字幕正文。用户需要详细疑点清单时再另行导出。
- 同步记录成片预设来源：实际探测、用户指定或仅画幅选项，不能把原视频尺寸等同于最终成片尺寸。
- 测试保留各模型原始结果及综合校准记录，区分识别、改写、分句和时间轴问题。不把综合校准稿当作单一模型独立准确率，不给没有人工参考稿支持的准确率。
