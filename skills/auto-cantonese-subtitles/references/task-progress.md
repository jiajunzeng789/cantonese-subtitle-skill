# 任务清单与反馈

安装和运行结果优先读取`setup_runtime.py`、`check_runtime.py`、`verify_models.py`及`transcribe.py`实际生成的进度与报告，具体位置见[runtime-setup.md](runtime-setup.md)。完整制作任务的清单由Agent汇总这些证据，不能只按对话中曾经说过“已安装”打勾。

## 状态与打勾依据

| 显示 | 记录状态 | 含义 |
|---|---|---|
| ⬜ | pending | 未开始 |
| 🔄 | running | 有实际执行任务正在运行 |
| ✅ | passed | 该步骤已完成且对应检查通过 |
| ⚠️ | review | 已有产物，但存在明确待核对项 |
| ❌ | failed | 此步骤执行失败 |
| ⏸️ | waiting | 正在等待前置条件或必要用户输入 |

每个检查项单独判断，不把“工具调用成功”当成“任务完成”。模型文件核查、依赖导入、模型加载分别记录。下例中的状态仅示范显示，不可照抄为本次结果。

```text
当前阶段：准备识别环境

✅ 素材检查：47秒
✅ 成片画幅：横屏
✅ 模型文件核查通过
✅ Whisper环境及模型加载通过
🔄 Qwen环境验证中
⬜ Whisper识别
⬜ Qwen识别
⬜ 文字与汽车术语校准
⬜ 单行断句与时间轴核对
⬜ SRT导出与结构检查
⬜ 回放同步验收
```

显示真实时长和实际成片设置。没有素材、未知画幅时相应步骤标为等待，环境准备仍可进行。回放验收未完成时保留待核对状态，不以结构检查通过代替。

## 什么时候提醒

- 开始任务时展示清单；进入新步骤、检查通过、失败、需用户处理或恢复时更新。
- 长任务在有执行机会时约每60秒提供简短更新：当前步骤、已耗时、最近进展和下一步。适当缩短工具等待，避免长时间阻塞后才汇报。软件不支持主动后台消息时，保存进度，并在取回执行权时立即汇报；不能保证跨Agent都有实时推送。
- 正在安装时明确“尚未开始识别”，正在识别时说明Whisper还是Qwen。可获取真实的已处理时长或下载字节数时再计算该步骤百分比，不用完成步骤数冒充整体耗时百分比。
- 日志暂时没有更新时说清“暂时没有新输出”，继续检查真实任务状态；不要用无信息的等待文案替代。

### 下载与安装进度

下载依赖时，更新中应尽可能包含：实际包名及版本、来源域名、下载或安装阶段、已下载量/总量、当前速度和耗时。只报告实际可取得的字段；未知字段写未知或省略，不能依据经验补成“约2GB”。

以安装器日志和下载量变化确认进度。只看到某个包文件被打开，不足以证明它正在下载；解析依赖、下载、解压和安装需要分别说明。包名变化时同步更新，不能始终显示“PyTorch还在下载”。

```text
🔄 正在准备Qwen依赖
当前包：填写实际包名及版本
下载源：填写实际来源域名
阶段：下载中 / 解析依赖 / 安装中 / 暂时无法确认
下载进度：填写实际已下载量和总量 无法取得则写未知
速度及耗时：填写实际可取得的数据
最近进展：填写最近一条可验证的变化
```

以上是字段模板，不是成功示例。只有总量和实时速度均可取得时，才估计本步骤剩余下载时间，并明确速度变化会影响估计。约60秒没有新进展时按环境恢复说明查进程、日志和文件变化，不将“耗时较长”直接判为网络慢或程序卡死。源连接较差时说明是否可换用国内镜像，不能为了更新提示而重复启动下载。

```text
🔄 正在安装Qwen依赖 已耗时2分钟
最近进展：下载已完成 正在安装
已完成：基础工具和Whisper环境检查
尚未开始音频识别
```

有真实进展才使用上面的具体表述；无法取得进度时明确说明未知。

## 失败反馈

失败后报告：失败步骤、可确认的错误、影响、保留了什么、日志位置、下一步及是否需要用户操作。没有完整错误时标为“原因待确认”，不提前认定安全防护或模型有问题。

```text
❌ Qwen环境准备失败
确认原因：填写日志中能支持的错误 或原因待确认
影响：双模型识别尚未完成
已保留：填写实际存在的缓存和已验证环境
错误日志：填写本机日志位置
下一步：填写对应检查或有依据的修复
需要你操作：无需操作 或说明具体操作及原因
```

同一种错误按环境恢复规则限制重试；失败步骤后面的相关任务标为等待，不全标失败。不需要用户处理的修复继续自行执行，不反复询问已明确的横竖屏等信息。

## 保存进度与续接

在本次工作目录 `.cantonese-subtitles/progress.json` 保存记录，日志在同目录 `logs/`。优先用临时文件写入后替换，避免中断导致状态文件只写一半。状态记录不写入发布字幕，日志和本机路径不提交GitHub。

建议记录结构：

```json
{
  "schema_version": 1,
  "input": {"path": "本机素材路径", "size": 0, "mtime_ns": 0},
  "final_layout": null,
  "updated_at": "实际时间及时区",
  "steps": [
    {
      "id": "whisper_environment",
      "status": "pending",
      "started_at": null,
      "finished_at": null,
      "evidence": null,
      "log_path": null,
      "task_id": null,
      "retry_count": 0,
      "error": null
    }
  ],
  "artifacts": [],
  "review_items": []
}
```

素材路径、大小和修改时间用于恢复时核对；改变素材、画幅或模型后重新检查相关步骤。可疑同名素材必要时计算校验值。保存实际起止时间、任务ID、证据、产物和待审位置；没有实际验证时不能填成功。

用户说“继续”后先查运行中的任务及产物，判断它已结束、仍运行还是未知，再决定是否重跑。不删除仍可能使用的临时文件，不并发修改同一环境。

## 交付摘要

分别报告文件生成、格式检查、内容及同步验收。给出实际字幕文件链接及待审位置。

```text
✅ SRT已导出
✅ 单行 标点 时间范围及重叠检查通过
⚠️ 2处专名需要确认
⚠️ 尚未逐条播放验收同步

字幕文件：填写实际文件
待审位置：填写实际记录
```

没有疑点时不人为制造待审项，有未决内容时不把整体清单全部打勾。用户已审阅确认的部分记录确认范围，不能外推成全片逐条声画同步合格。
