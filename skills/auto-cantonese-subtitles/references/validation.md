## 验证边界

- 新建环境的安装使用过本机pip下载缓存；模型也复用了已有完整缓存。未测试零缓存下载全部模型所需时间，不能承诺首次准备耗时。
- 国内镜像本次检查未能取得所需索引结果，脚本明确提示并采用官方源；镜像不保证在每个网络都可用或更快。
- 本轮没有重新跑完整9分31秒视频；长片分窗执行、偏移与续接用多窗口真实短样本验证，实际长片的接缝仍需校准。
- 没有逐条回听验收这些测试产物，不以文件结构检查代替识别准确性或声画同步检查。
- 未对Windows、Linux和各Agent的权限层分别完成实机验收。平台不支持固定版本的预编译包时应明确报错，不自动改版本或临时编译大型运行库。
- 关键依赖已固定，但间接依赖并非所有平台的完整锁文件；成功环境会记录实际关键版本，后续升级需重新验证。

运行自动化故障测试：

```sh
python -m unittest discover -s tests -v
```
